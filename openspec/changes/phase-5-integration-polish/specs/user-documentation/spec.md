## ADDED Requirements

### Requirement: Admin Guide LeaderP
A markdown document docs/guides/admin-leaderp.md SHALL exist covering inventory, PO, SO, license, and after-sales workflows.

#### Scenario: Admin guide covers PO workflow
- **WHEN** developer reads admin-leaderp.md
- **THEN** the document MUST include step-by-step instructions for creating and receiving a purchase order

### Requirement: Gym Owner Guide
A markdown document docs/guides/gym-owner.md SHALL exist covering member, subscription, invoice, check-in, and license workflows.

#### Scenario: Gym owner guide covers license input
- **WHEN** developer reads gym-owner.md
- **THEN** the document MUST include instructions for inputting a license key and what happens when it expires
